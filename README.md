# GRENET Interactive Website

Static, responsive one-page website for **GRENET** and **Jargal Purevsambuu**.

## Included

- Interactive ESG platform demo with four modules
- Detailed services and business model
- ESG readiness mini-assessment
- Target customer segmentation and product roadmap
- Projects and founder experience
- Mongolian / English language toggle
- Dark / light mode
- Responsive mobile navigation
- Local CV and Medehui business concept PDF links
- No external JavaScript libraries or server dependency

## Open locally

Open `index.html` in a modern browser. For the most reliable local experience, run a simple web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

Upload the complete folder to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static hosting provider.

Financial figures and impact percentages shown under the expandable business-model section are explicitly presented as preliminary assumptions from the Medehui concept deck, not achieved results or guaranteed returns.
